# SkinLedger · 饰账

Skin 表示饰品，Ledger 表示清晰的成本账本。中文“饰账”强调成本核算，不暗示收益保证。

## 界面体系

- 原色：深绿 `#173e34`、操作绿 `#28634f`、暖白 `#f6f7f3`。
- `ui/tokens.css` 按原色 → 语义 → 组件令牌组织，`ui/brand.css` 统一两端外观。
- 字体使用系统字体，不请求远程字体；数值采用等宽数字。
- 顶部品牌区 → 使用流程 → 扫描控制 → 指标 → 筛选 → 数据质量 → 明细。
- 对比色不承担唯一语义；失败有文字，状态有标签，交互有键盘焦点。
- `ui/logo.svg` 为项目原创几何标志；`npm run build:brand` 生成图标和仓库封面。
